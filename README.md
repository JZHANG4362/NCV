# NCV: reproduce the main text and Supplement

Run all commands below from the repository root.

## Environment setup

```bash
conda env create -f environment.yml
conda activate ncv-reproduction
```

## Reproduce figures and tables from saved results

```bash
python reproduce.py cached
```

This redraws the 38 numerical figures and generates 89 tables. PDFs are in
`outputs/figures/`; LaTeX table fragments are in `outputs/tables/` and
`outputs/local_embedding_tables/`. To generate only tables:

```bash
python reproduce.py tables
```

## Run all experiments from scratch

First try the small Iris example:

```bash
python scripts/run_experiments.py smoke --execute
```

Run every experiment and export its figures and tables:

```bash
python scripts/run_experiments.py all --execute --workdir runs/full
python reproduce.py cached --results-root runs/full --output outputs/full
```

Running all experiments can be time consuming. We recommend running one section
at a time with `scripts/run_experiments.py`. Run the corresponding command below
from the repository root:

```bash
python scripts/run_experiments.py case1 --execute        # Section 4.1
python scripts/run_experiments.py case2 --execute        # Section 4.2
python scripts/run_experiments.py case3 --execute        # Section 4.3
python scripts/run_experiments.py case4 --execute        # Section 4.4
python scripts/run_experiments.py sensitivity --execute  # Section 4.5
python scripts/run_experiments.py embeddings --execute   # Section 4.6
```

Each command recomputes that section's experiments and saves results under
`runs/<group>/`, for example `runs/case1/`. The README in each section folder
lists the corresponding figures, tables, and output files.

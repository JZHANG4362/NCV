# Other validity indices for Section 4.6

These scripts compute VRC, WG, WB, DBCV, CVDD, VIASCKDE, DCSI, and DB.
`generate_manifold_bar_summary_tex.py` combines these results with
`../silhouette/` to draw Supplement Figures S7–S37.

See the [Section 4.6 instructions](../README.md) for commands, figure filenames,
and main text Tables 4–5.
